# TIER_DOWNGRADE

Class and severity: H2

**What fired.** The router downgraded the active tier (a gate failed or a rung fired).

**What the system already did.** Sleeves the new tier does not allow go reduce-only (INV-13).

**What you own.** Read the binding gate on the Strategy screen. An upgrade later needs every gate and your signature.

**Resolve when.** Acknowledged with rationale; the downgrade itself stays. Incidents are never dismissed; resolving one needs a written rationale (§7.9).
