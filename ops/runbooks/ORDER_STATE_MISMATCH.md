# ORDER_STATE_MISMATCH

Class and severity: S2

**What fired.** The OMS and the venue disagree about an order.

**What the system already did.** Entries blocked on the venue; restart reconciliation runs.

**What you own.** Compare the venue's order history with the OMS record in the evidence.

**Resolve when.** Reconciled; the venue's state is recorded as truth. Incidents are never dismissed; resolving one needs a written rationale (§7.9).
