# WS_RESYNC_PENDING

Class and severity: D2

**What fired.** A venue websocket dropped and state is being re-synced.

**What the system already did.** Entries on the venue wait for the resync.

**What you own.** Usually nothing; if it repeats, check the venue status page.

**Resolve when.** Resync complete. Incidents are never dismissed; resolving one needs a written rationale (§7.9).
