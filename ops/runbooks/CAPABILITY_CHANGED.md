# CAPABILITY_CHANGED

Class and severity: H2

**What fired.** A venue's capability snapshot changed (order types, stops, fees).

**What the system already did.** Entries blocked on the venue until you approve the new snapshot.

**What you own.** Read the diff; approve with CAPABILITY_APPROVE if the change is acceptable.

**Resolve when.** Snapshot approved or venue disabled. Incidents are never dismissed; resolving one needs a written rationale (§7.9).
