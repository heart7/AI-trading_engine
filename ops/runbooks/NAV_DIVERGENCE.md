# NAV_DIVERGENCE

Class and severity: D1

**What fired.** Ledger NAV and venue-balance NAV differ by more than 0.1%.

**What the system already did.** NAV provisional; entries blocked.

**What you own.** Compare balances per venue in the evidence; usually a missing fill or transfer.

**Resolve when.** Paths agree within 0.1%. Incidents are never dismissed; resolving one needs a written rationale (§7.9).
